
# AI Air Writing

## Project Description
AI Air Writing is a computer vision project that allows users to draw in the air using their index finger.

## Technologies Used
- Python
- OpenCV
- MediaPipe
- NumPy

## Features
- Real-time hand detection
- Finger tracking
- Air writing
- Clear drawings
- Save drawings
- Colour selection
- Brush size adjustment

## How to Run
Run main.py in PyCharm.
